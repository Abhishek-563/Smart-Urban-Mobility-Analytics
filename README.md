## 📌 Project Overview

Urban bike-sharing services generate thousands of rentals daily. This project analyzes rental behavior, weather influence, seasonal demand, and operational efficiency to provide actionable business insights.

The analysis transforms raw operational data into executive-level KPIs and visual dashboards using Python.

---

## Dataset

Seoul Bike Sharing Demand Dataset

UCI Repository

https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand

## Business Insights

- Summer generates maximum rentals.
- Rush hours drive demand.
- Rainfall negatively impacts usage.
- Snowfall significantly reduces rentals.
- Temperature positively affects demand.
- Weekday usage is higher due to commuting.
